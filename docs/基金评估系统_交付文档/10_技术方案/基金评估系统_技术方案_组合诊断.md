# 技术方案 TP-03 · 组合多层级诊断（红黄绿）

> **对应模块**：§3.6 组合与配置（BRD 模块五 FR-20~24/37，DC-006）
> **目标**：将组合「自动多层级诊断（红黄绿）」从 BRD 散落阈值落地为**可直接编码**的五维判定表与整体评级合成规则。
> **前置依赖**：BRD BR-5.4/BR-5.6/BR-5.10、详细设计 §3.6、技术规格 portfolio/diagnosis

---

## 1. 范围与目标

- 输入：组合权重 `portfolio_weights`（成分 code + weight）+ 用户风险测评结果 `risk_type`。
- 输出：五维（股债 / 海外 / 行业 / 风格 / 个基）每维状态（红/黄/绿）+ 建议 + **整体评级** + 再平衡提示。
- 约束：阈值集中配置（§3.6.6，便于投资导师审定 OQ-14）。

## 3. 五维判定表（可执行）

> 阈值常量集中于 `diagnosis_thresholds` 配置（§3.6.6）。以下为默认（可导师审定）。

### 3.1 股债结构（asset allocation，联动风险测评与 TP-05 中枢，修正 E8）
| 风险偏好 `risk_type` | 权益目标区间 | 固收+货币目标 |
|------|------|------|
| 保守 | 20%–40% | 60%–80% |
| 稳健 | 40%–60% | 40%–60% |
| 进取 | 60%–80% | 20%–40% |

- 判定：实际权益占比偏离目标区间上/下限 > 10pct → 🟡（偏离过大，建议再平衡）；落在目标区间内 → 🟢；单一资产占比 > 90% → 🔴。
- 与 TP-05 股债中枢（ERP/估值分位推导）**联动**：TP-05 中枢建议作为目标区间的参考输入，三者（风险测评→股债中枢→组合诊断）必须同一链条，避免教学自相矛盾。

### 3.2 海外暴露（overseas）
| 条件 | 状态 | 建议 |
|------|------|------|
| 单一海外区域占比 > 25% | 🟡 | 区域集中+汇率风险 |
| 海外合计 > 40% | 🟡 | 整体海外敞口偏高，注意时区/汇率 |
| 海外合计 ≤ 40% 且单区 ≤ 25% | 🟢 | 海外配置适度 |

### 3.3 行业集中度（industry，来自持仓穿透 §3.9）
| 条件（按申万一级行业聚合权重） | 状态 |
|------|------|
| HHI > 0.25 或 单一行业 > 60% | 🔴 高度集中 |
| 单一行业 40%–60% 或 HHI 0.15–0.25 | 🟡 |
| 单一行业 < 40% 且 HHI < 0.15 | 🟢 |

```python
def industry_dim(weights):
    ind = aggregate_by_industry(weights)        # code → 行业 → 权重和
    hhi = sum(w*w for w in ind.values())
    top = max(ind.values())
    if top > 0.60 or hhi > 0.25: return "red"
    if top > 0.40 or hhi > 0.15: return "yellow"
    return "green"
```

### 3.4 风格暴露（style，来自风格箱 §3.3.5）
| 条件 | 状态 |
|------|------|
| 成长风格暴露 > 70% 且 `risk_type=保守/稳健` | 🔴 风格与风险偏好错配 |
| 成长风格暴露 > 70%（其余风险偏好） | 🟡 成长集中 |
| 价值/平衡为主 或 成长 ≤ 70% | 🟢 |

### 3.5 个基隐患（single fund，BR-5.10，逐成分）
| 条件（近 1y） | 状态 | 提示 |
|------|------|------|
| 相对基准超额收益 < −15% **或** 最大回撤 > 30% | 🔴 | 预警：评估止损/减仓（相对基准+回撤，非绝对收益，修正 E9） |
| 收益率 > 30% | 🟡(📈) | 软提示：可考虑部分止盈（避免硬止盈的行为偏差，修正 E9） |
| 规模 > 500 亿（臃肿） | 🟡 | 规模臃肿提示 |
| 综合费率(管理+托管) > 2.0% | 🟡 | 高费率提示（含托管，修正 E12） |
| 换手率 > 300% | 🟡 | 高换手提示 |

> 任一成分 🔴 → 该维整体 🔴；否则存在 🟡 则该维 🟡。

## 4. 整体评级合成

```python
RED, YELLOW, GREEN = 2, 1, 0
def overall(per_dim: dict) -> str:
    states = per_dim.values()                    # 五维状态
    if any(s == "red" for s in states): return "red"        # 任一红 → 整体红
    if any(s == "yellow" for s in states): return "yellow"  # 否则任一黄 → 整体黄
    return "green"

def diagnose(portfolio_id) -> dict:
    w = load_weights(portfolio_id)               # {code: weight}
    per = {
        "asset":   asset_dim(w),
        "overseas":overseas_dim(w),
        "industry":industry_dim(w),
        "style":    style_dim(w, risk_type_of(portfolio_id)),
        "single":   single_fund_dim(w),
    }
    rating = overall(per)
    rebalance = suggest_rebalance(per, w)        # 见 §5
    return {"per_dim": per, "rating": rating,
            "advice": build_advice(per), "rebalance": rebalance}
```

## 5. 再平衡提醒（§3.6.2）

- 触发：整体 `yellow/red` 或某维偏离目标权重 > `REBALANCE_DRIFT`（默认 5%）。
- 输出：`rebalance` 列表，形如 `{dim, current, suggest, action}`（如股债：权益 70%→60%）。

## 6. 边界与异常

| 场景 | 处理 |
|------|------|
| 组合仅 1 只基金 | 行业/风格维度退化为该基金自身属性，提示"单基无分散" |
| 持仓穿透缺失 | 行业维度 `unavailable`，不参与红判定，标"待穿透" |
| 风险测评缺失 | 风格维度按默认"稳健"判定，提示补全测评 |
| 阈值配置变更 | 全部维度用同一 `diagnosis_thresholds` 版本，结果带 `threshold_ver` |

---

## 7. 测试验收（test oracle）

| 验收项 | 基准 |
|--------|------|
| 股债边界(稳健目标40–60%) | 权益=30%(偏离>10pct)→黄；=50%(目标内)→绿；单一资产>90%→红 |
| 行业集中 | 单行业 65% → 红；45% → 黄；30% → 绿 |
| 个基止损(相对基准) | 近1y 超额<−15% 或 回撤>30% → 红 |
| 整体合成 | 四绿一黄 → 黄；任红 → 红 |
| 阈值可配 | 改 `diagnosis_thresholds`/`risk_type` 目标区间后结果随之变化 |
