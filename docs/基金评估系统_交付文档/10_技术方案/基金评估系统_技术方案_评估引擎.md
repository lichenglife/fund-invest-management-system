## 3. 关键算法与代码逻辑

### 3.1 五因子口径与原始指标映射（闭合 BK-1/BK-2）

```python
# 唯一权威因子集（与 BRD BR-2.2 / 技术规格 line 465 对齐）
SCORING_FACTORS = ["ret", "risk", "perf", "scale", "manager"]
DEFAULT_WEIGHTS = {"ret": 0.30, "risk": 0.25, "perf": 0.20,
                   "scale": 0.15, "manager": 0.10}   # 权重和=1，可调

# 每个因子的「原始指标」→ 取值函数（均在 window 滚动区间上计算）
FACTOR_RAW = {
    "ret":     lambda nav, f: annualized_return(nav, window=f.window),        # 年化收益(%)
    "risk":    lambda nav, f: max_drawdown(nav, window=f.window),             # 最大回撤(返回负值, 如 -0.25; 越负越差)
    "perf":    lambda nav, f: sharpe_ratio(nav, window=f.window, rf=f.rf),    # 夏普比率（风险调整后收益）
    "scale":   lambda nav, f: scale_health(f.aum_yi),                         # 规模健康度(非质量线性分): 2~500亿满分
    "manager": lambda nav, f: manager_excess(nav, f),                         # 任职超额收益=区间收益−同类基准(标注为任期业绩非能力)
}
def scale_health(aum_yi):
    """规模健康度: 清盘风险门槛而非质量正向。2~500亿→100; <2亿递减(清盘风险); >500亿略降(船大难掉头)。"""
    if aum_yi is None: return None
    if aum_yi < 2:    return max(0.0, aum_yi/2*100)        # 小于2亿, 线性至0
    if aum_yi <= 500: return 100.0
    return max(60.0, 100 - (aum_yi-500)/100)              # 超500亿缓降, 下限60
def manager_excess(nav, f):
    """任职超额收益 = 区间年化收益 − 同类基准区间年化收益; 反映任期业绩相对同类, 非经理能力(含β/幸存者偏差)。"""
    bench_nav = load_nav(f.benchmark_code, f.window) if getattr(f, "benchmark_code", None) else None
    if bench_nav is None: return None
    return annualized_return(nav, window=f.window) - annualized_return(bench_nav, window=f.window)
# 方向：ret/perf/scale/manager 越高越好；risk(最大回撤, 负值) 越接近0越好。
# 回撤符号约定：max_drawdown 返回负值（如 -0.25=回撤25%），百分位按原值排名 → 越负排名越低=子分越低（正确方向）。
# 共线提示（专家评审 E4）：ret/risk/perf 同源于一条 NAV，perf(夏普)已含风险调整；综合分为"指示性"分解，
#   权重调节表达用户风险偏好而非精确归因。scale/manager 定义已修正：规模不作线性质量正向、经理不作收益归因。
```

> **指标计算锚点**：年化收益/最大回撤/夏普 直接复用 技术规格 `annualized_return` 等（line 462）+ `empyrical`；`aum_yi` 来自 `funds.scale`；`manager_tenure_return` 来自 `funds.tenure_return`。核心指标与公开源对账误差 < 0.5%（BRD 验收①）。

### 3.2 横截面百分位评分（闭合 BK-3）

核心原则：**百分位分位表由夜算（批算）统一产出并缓存；在线查询只查表，不重算**。

```python
def build_percentile_tables(window: str):
    """夜算：对全市场基金，按 asset_class(底层资产类别) 分组计算各因子原始值，再转百分位。"""
    raw = {ft: {} for ft in SCORING_FACTORS}          # raw[ft][code] = 原始指标值
    for code in all_fund_codes():
        f = load_fund_meta(code)                       # type / aum / benchmark_code
        nav = load_nav(code, window)
        if nav is None or len(nav) < MIN_POINTS:       # 数据不足跳过该因子
            continue
        for ft in SCORING_FACTORS:
            raw[ft][code] = FACTOR_RAW[ft](nav, f)
    # 每个因子在每个 asset_class(equity/debt/money/alt/qdii) universe 内做百分位排名
    # 同跟踪沪深300的 ETF 与指数基金归入同一 equity 组（修正专家评审 E5: 不按交易场所分组）
    pct_tables = {}
    for ft in SCORING_FACTORS:
        pct = {}
        for code, v in raw[ft].items():
            if v is None: continue
            cls = asset_class(code)
            grp = [vv for c2, vv in raw[ft].items() if c2 != code and asset_class(c2)==cls and vv is not None]
            grp.append(v)
            pct[code] = percentile_rank(v, grp) * 100
        pct_tables[ft] = pct
    # 货基/货币: 不参与五因子综合分排名(现金管理品无可比性), 其 composite 标 N/A(见 §5)
    redis.set(f"fund:pct:{window}", json.dumps(pct_tables), ex=86400)   # 日级刷新
    return pct_tables

def sub_scores(code, window) -> dict:
    """在线：直接查分位表，O(1)。缺失因子 s_k=None。"""
    pct = json.loads(redis.get(f"fund:pct:{window}"))
    return {ft: pct[ft].get(code) for ft in SCORING_FACTORS}

def composite(sub: dict, weights: dict) -> tuple[float, dict]:
    """综合分 = Σ(w_k·s_k)/Σw_k，仅对有效因子求和。"""
    eff = {k: v for k, v in sub.items() if v is not None}
    num = sum(weights[k] * eff[k] for k in eff)
    den = sum(weights[k] for k in eff)
    comp = num / den if den else None
    contrib = {k: weights[k] * eff[k] for k in eff}     # 因子贡献分解
    return comp, contrib
```

> **一致性保证（ADR-002）**：在线 `get_score` 不复算百分位，仅 `sub_scores` 查表 + `composite` 即时加权（权重调节即时重算，但分位表不变）。仪表盘/筛选/组合共享同一 `fund:pct:{window}` 与 `fund:score:{code}`，无漂移。

### 3.3 Brinson 归因（数据流落实，§3.3.8.2）

```python
def brinson_attribution(code, window) -> dict:
    if fund_type(code).first_level() not in BRINSON_SCOPE:   # ["mixed","stock"]
        return None
    bench = benchmark_of(code)                                # 股→沪深300/混→中证800
    w_b = benchmark_weights(bench, window)                    # 基准成分权重(缺失则标 unavailable)
    R_b = asset_returns(bench, window)                        # 基准成分收益
    if w_b is None or R_b is None:
        return {"unavailable": True, "reason": "benchmark_weights_missing"}
    A_sum = S_sum = I_sum = 0.0; period_active = []
    for p in split_window(window):                            # 按持仓报告期切片
        hp = load_holdings(code, as_of=p.end)                 # 期末持仓快照(披露真实权重, 和<1)
        disc = {h.stock: h.weight for h in hp}
        resid_w = max(0.0, 1.0 - sum(disc.values()))          # 未披露部分→"其他/现金"残差桶
        w_p = {**disc, "OTHER_CASH": resid_w}
        R_p = {**asset_returns_for(hp, p), "OTHER_CASH": cash_return(p)}
        w_b_p = {**w_b, "OTHER_CASH": max(0.0, 1.0 - sum(w_b.values()))}
        R_b_p = {**R_b, "OTHER_CASH": cash_return(p)}
        A = sum((w_p[i]-w_b_p[i])*R_b_p[i] for i in w_p)
        S = sum(w_b_p[i]*(R_p[i]-R_b_p[i]) for i in w_p)
        I = sum((w_p[i]-w_b_p[i])*(R_p[i]-R_b_p[i]) for i in w_p)
        A_sum += A; S_sum += S; I_sum += I
        period_active.append(A+S+I)
    total_active = geometric_link(period_active)              # ∏(1+r_t)-1 复利主动收益
    k = total_active/(A_sum+S_sum+I_sum) if (A_sum+S_sum+I_sum) else 0.0   # Carino/Frongello 平滑
    A, S, I = A_sum*k, S_sum*k, I_sum*k
    return {"allocation": A, "selection": S, "interaction": I,
            "active_return": A+S+I, "scope": "mixed/stock", "multi_period": "geometric_link"}
# 指数/ETF：不显示 Brinson，改显 TE= tracking_error(nav, bench)、IR= alpha/TE
# 债基：不显示
```

> 多期处理（修正 E2）：各期主动收益**几何链接** `geometric_link=∏(1+r_t)−1` 得总主动收益，再按 Carino/Frongello 平滑系数 `k=总主动/算术和` 分配至 Allocation/Selection/Interaction，保证三效应之和=复利主动收益。权重处理（修正 E1）：用**披露真实权重**（和<1），未披露部分归入"其他/现金"残差桶并与基准残差匹配，避免前十大归一虚增主动权重约 40pct。持仓缺失 → `unavailable=True`。

### 3.4 PEG/ERP 基金层代理（§3.3.7，含守卫）

```python
def research_metrics_proxy(code) -> dict:
    if not RESEARCH_PROXY_GUARD:                  # 守卫未开 → 一律 None，禁止 naive 计算
        return {"peg": None, "erp": None, "available": False}
    typ = fund_type(code).first_level()
    if typ == "bond":                             # 债基无 PEG 代理
        return {"peg": None, "erp": None, "available": False, "reason": "bond_no_peg"}
    hp = load_holdings(code)
    if not hp:                                    # 持仓缺失 → 回退跟踪基准
        hp = benchmark_holdings(benchmark_of(code))
    if not hp:                                    # 仍不可得
        return {"peg": None, "erp": None, "available": False, "reason": "holdings_missing"}
    # PEG：按持仓加权个股 PEG_i = PE_i / EPS_growth_i(%)；剔除 PE<=0(亏损)与 growth 越界/缺失个股(不置0)
    pegs, ws = [], []
    for h in hp:
        pe = pe_of(h.stock); g = eps_growth_of(h.stock, window="TTM")   # 须定义: 一致预期或TTM同比
        if pe is None or pe <= 0 or g is None or not (0 < g < 100):
            continue
        pegs.append(pe/g); ws.append(h.weight)
    peg = weighted_mean(pegs, ws) if pegs else None
    # ERP（盈利收益率利差, Fed Model 思路, 非严格ERP）：按市值风格拆分大/小盘
    ey_large  = ey_weighted(hp, style="large");  ey_small = ey_weighted(hp, style="small")
    erp = {"large": (ey_large - cgb_10y()) if ey_large else None,
           "small": (ey_small - cgb_10y()) if ey_small else None,
           "ey_large": ey_large, "ey_small": ey_small}
    return {"peg": peg, "erp": erp, "available": (peg is not None) or (erp["large"] is not None),
            "name_suffix": "(代理)", "note": "相对高低提示，非绝对结论；ERP 为盈利收益率利差代理"}
```

### 3.5 风格箱（§3.3.1，简要，复用技术规格；闭合 E13）

九宫格（size: 大/中/小；value_growth: 价值/平衡/成长）= 持仓市值分布定 size + 估值/成长因子定 value_growth；并用历史收益对价值/成长因子做回归交叉验证（回归载荷与持仓法不一致 → `cv_flag=True`，前端提示）。

> **不适用类型与回归窗口（闭合 E13，🟢 低）**：① 风格箱**仅对权益类（equity / 偏股 mixed）有效**；债基 / 货基 / QDII / 另类（alt）**不显示风格箱**，改显其专属标签（如债基→久期/信用风格，货基→剩余期限），避免对不适用资产误用九宫格。② 回归交叉验证**固定窗口 = 与因子同窗口（默认 3y）**，并披露 `reg_window`，窗口外不做外推；载荷不显著（`|load|<0.3` 且 `p>0.1`）时 `cv_flag=True` 提示。

## 5. 边界与异常

| 场景 | 处理 |
|------|------|
| NAV 点数 < `MIN_POINTS`（如 < 60 日） | 该因子 `s_k=None`，综合分分母缩小；全因子缺失 → `composite=None` |
| 某类型 universe 样本数 < 5 | 退化为全市场 universe 百分位，标 `universe="all"` |
| 货基/货币 | 不参与五因子综合分排名，`composite` 标 `N/A`（现金管理品无可比性） |
| `max_drawdown` 返回正值 | 统一取负（−值），否则百分位方向反转（修正 E5） |
| 权重调节后和≠1 | 拒绝并 40001；前端滑杆约束和=1 |
| 持仓缺失 | Brinson `unavailable`；PEG/ERP 回退基准，再不可得 `available=False` |
| `RESEARCH_PROXY_GUARD=False` | 研究指标 PEG/ERP 一律 None（防 naive） |
| 对账误差 > 0.5% | `cv_flag=True`，核心指标卡提示"建议复核" |

---

## 6. 并发与性能边界（§2.22/§3.3.9）

- 百分位分位表 → **夜算** `ProcessPoolExecutor`（CPU 密集），结果写 PG + Redis（`fund:pct:{window}` 日级，`fund:score:{code}` 30min）。
- 在线 `get_score` 仅查 Redis/分位表，未命中才 `score_one` 单基（成本可控），保证多副本一致。
- 权重变更 → `composite` 即时重算 + `redis.delete(fund:score:{code})` 失效。

---

## 7. 测试验收（test oracle）

| 验收项 | 基准 | 来源 |
|--------|------|------|
| 核心指标对账 | 与公开源误差 < 0.5% | BRD 验收① |
| 综合分可解释 | 各 `s_k` 与 `contrib` 可展开，权重变动即时反映 | BRD 验收② |
| 百分位一致性 | 在线综合分 == 夜算综合分（同 window/weights） | ADR-002 |
| Brinson 恒等式 | `active_return == allocation+selection+interaction`（几何链接后平滑系数保证） | §3.3.8.2 |
| 货基排除 | 货基 `composite == N/A` | E5 |
| PEG 守卫 | PE≤0 个股跳过，组合 `peg` 可为 None | E7 |
| 因子口径 | 子分键集 == `{ret,risk,perf,scale,manager}` | BK-1 |

## 8. 端到端执行流程

```
采集(§3.1) → NAV/holdings/funds 落 PG
   ↓ 夜算 18:30 (§3.14)
build_percentile_tables(window) → fund:pct:{window} + scores + research_metrics
   ↓ 在线
GET /api/funds/{code}/score → sub_scores(查表) → composite(即时加权) → 响应
权重调节 → composite 重算 + 失效缓存
```
