## 3. 高位四维排查判定表

> 维度统一输出 4 阶段：低估 / 合理 / 偏高 / 高估，附带操作暗示。
> **分位口径与免责（闭合 E11）**：所有"分位"指标须**固定并披露历史回看窗口**（估值/涨幅统一取 **近 10 年滚动分位**，与 TP-01 §3.2 百分表窗口一致），不可随意切换；分位隐含"相对自身历史"的均值回归假设，但 A 股存在结构性断点（如注册制、外资定价权变化），**分位偏高≠即将回调**，仅作"相对贵贱"提示，严禁作为择时信号。须与**绝对估值（ERP / 股息率）**及**债券利差**交叉验证，任一维度给出"偏高"时输出交叉验证标注（`cross_check` 字段），避免单指标误判。

| 维度 | 输入指标 | 偏高/高估阈值 | 操作暗示（偏高→高估） |
|------|----------|----------------|----------------------|
| 估值 | 宽基 PE **近10年**历史分位 | >70% 偏高 / >90% 高估 | 分批止盈→降低权益仓位（须 ERP 交叉验证） |
| 涨幅 | 近 3y 累计涨幅分位（窗口固定） | >80% 偏高 / >95% 高估 | 警惕回撤→减少追高 |
| 情绪 | 换手率/融资余额/新开户环比 | 环比>+30% 偏高 / +60% 高估 | 情绪过热→逆向减仓 |
| 杠杆/资金 | 两融余额/GDP 比、ETF 净流出 | 两融>2.8% 偏低 / >3.5% 高估 | 杠杆风险→控仓 |

```python
PERCENTILE_WINDOW = "10y"   # 固定回看窗口, 与 TP-01 百分表一致(闭合 E11)

def high_signal_dim(indicators) -> dict:
    out = {}
    out["valuation"] = stage(indicators.pe_percentile_10y, lo=70, hi=90)
    out["gain"]      = stage(indicators.cum3y_percentile, lo=80, hi=95)
    out["sentiment"] = stage(indicators.turnover_mom, lo=30, hi=60, unit="pct_mom")
    out["leverage"]  = stage(indicators.margin_to_gdp, lo=2.8, hi=3.5, unit="ratio")
    # 交叉验证(闭合 E11): 估值偏高时, 若 ERP 仍高(股权性价比优)则降级标注
    if out["valuation"]["stage"] in ("偏高", "高估"):
        out["valuation"]["cross_check"] = cross_validate_valuation(indicators)
    return out   # 每维含 {stage, hint, cross_check?}
```

## 4. 股债中枢建议

> **ERP 拆分市值风格（闭合 E10）**：原 `equity_center` 用宽基整体 PE 单一 ERP，未区分大/小盘——A 股大小盘估值与风险溢价长期分化（小盘 ERP 系统性高于大盘）。改为**分别计算大盘 ERP 与 小盘 ERP**，中枢取两者加权（默认按自由流通市值 7:3），避免单一宽基口径误导；阈值 `(4%/40%)` 标注为**初值**，须做敏感性测试（`SENSITIVITY_TEST` 开关）后方可写入 `macro_thresholds` 正式版。

```python
ERP_HI, ERP_LO = 0.04, 0.02     # 初值阈值, 待敏感性测试回测(闭合 E10)
PE_PCT_HI, PE_PCT_LO = 70, 40
LARGE_SMALL_W = (0.7, 0.3)      # 大盘/小盘权重(自由流通市值近似)

def _erp_one(index: str) -> float:
    return 1.0 / pe_of(index) - cgb_10y()     # 单指数股权风险溢价(Fed Model)

def equity_center(advice_inputs) -> dict:
    erp_l = _erp_one("CSI300" if False else "large_cap_index")   # 大盘 ERP
    erp_s = _erp_one("small_cap_index")                          # 小盘 ERP
    erp   = LARGE_SMALL_W[0]*erp_l + LARGE_SMALL_W[1]*erp_s       # 加权 ERP
    pe_pct = pe_percentile(broad_index, window=PERCENTILE_WINDOW) # 10y 固定窗口(E11)
    # ERP 高 + 估值低 → 中枢上移; ERP 低 + 估值高 → 中枢下移
    if erp > ERP_HI and pe_pct < PE_PCT_LO:   center, bias = 70, "+10"
    elif erp < ERP_LO and pe_pct > PE_PCT_HI: center, bias = 40, "-10"
    else:                                     center, bias = 55, "0"
    return {"equity_center": center, "bias": bias,
            "erp": erp, "erp_large": erp_l, "erp_small": erp_s,
            "pe_percentile": pe_pct, "window": PERCENTILE_WINDOW,
            "note": "中枢为长期配置参考, 非短期择时; 阈值经敏感性测试前为初值"}
```

> 与组合诊断（TP-03 股债维）联动：中枢建议可作为组合目标权重的输入（E8 已联动 `risk_type` 推导权益区间）。

## 5. 外围传导与次日开盘研判

- 数据：隔夜美股（标普/纳指）、中概（金龙指数）、A50 期货。
- 休市判定：`is_market_closed()` → 标"暂无"；非休市 → 生成次日开盘研判（高/平/低 + 一句话依据）。
- 实现：`peripheral_signal()` 返回 `{us, csi, a50, open_bias, text}`。

---

## 6. 边界与异常

| 场景 | 处理 |
|------|------|
| 指标数据缺失 | 该维标"暂无"，不计入高位综合判定 |
| 休市 | 次日研判="暂无" |
| 阈值配置变更 | 同 `macro_thresholds` 版本，结果带 `threshold_ver` |

---

## 7. 测试验收

| 项 | 基准 |
|----|------|
| 估值阶段 | 近10年 PE分位 95% → 高估；50% → 合理（E11 窗口固定） |
| 股债中枢 | 加权ERP高+低估 → 中枢 70/+10；返回 erp_large/erp_small（E10） |
| 交叉验证 | 估值"偏高"时必带 cross_check 字段（E11） |
| 外围休市 | 休市时 open_bias="暂无" |
