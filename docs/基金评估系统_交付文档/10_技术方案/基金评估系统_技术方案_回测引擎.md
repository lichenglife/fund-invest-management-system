## 3. 定投回测 `_run_dca`

> **NAV 口径统一（闭合 E3）**：所有回测统一使用**复权单位净值（后复权）** `load_nav(code, ..., adjusted=True)`。后复权净值已把历史分红按"再投资"折算进净值序列，**等同于分红再投**，因此**不再单独设置分红再投逻辑**——这从根上消除了"复权净值已含分红"与"`DIVIDEND_MODE="reinvest"`"的双重计矛盾（原 TP-04 §3.1 的 `DIVIDEND_MODE` 常量删除）。
> - 若后续确有"单位净值 + 除息再购"需求，须另开 `MODE="unit_nav"` 分支独立实现并配置分红到账日，与复权口径互斥，不得同时生效。
> - `final_val`（终值）须扣**赎回费**后参与 IRR，避免定投收益虚高。

```python
FREQ_RULES = {"weekly": "W-MON", "monthly": "M", "quarterly": "Q"}
BUY_FEE_RATE = 0.0015        # 单边申购费(默认, 可配); 按扣款金额计
REDEEM_FEE_BY_HOLD = {        # 赎回费阶梯(按最低持有时长); 默认取>365天档
    "d7":   0.015,  "d30": 0.005,  "d365": 0.0025,  "gt365": 0.0
}
DEF_REDEEM_FEE = REDEEM_FEE_BY_HOLD["gt365"]   # 默认长期持有档(可配)

def _run_dca(account_id, params: dict) -> dict:
    code   = params["code"]
    freq   = params["freq"]                 # weekly/monthly/quarterly
    amount = params["amount"]               # 每期金额
    start, end = params["start"], params["end"]
    # 后复权净值: 已含分红再投, 绝不再叠加 DIVIDEND_MODE
    nav = load_nav(code, start, end, adjusted=True).resample(FREQ_RULES[freq]).last().ffill()
    invest_days = nav.index                 # 各定投扣款日(交易日)
    shares, cum_cost, cash_flow = 0.0, 0.0, []
    for day, nav_i in zip(invest_days, nav.values):
        buy = amount / (nav_i * (1 + BUY_FEE_RATE))   # 申购扣费后份额
        shares += buy
        cum_cost += amount
        cash_flow.append((day, -amount))              # 投入现金流, 用于 IRR
    gross_val = shares * nav.values[-1]               # 赎回前市值
    final_val = gross_val * (1 - DEF_REDEEM_FEE)      # 扣赎回费终值(闭锁 E3 漏计)
    irr = xirr(cash_flow + [(invest_days[-1], final_val)])
    return {"cum_invest": cum_cost, "gross_value": gross_val,
            "redeem_fee": gross_val - final_val,
            "final_value": final_val,
            "profit": final_val - cum_cost, "irr": irr,
            "max_drawdown": max_dd(nav), "shares": shares}
```

> 三情景（保守/基准/乐观）由 `dca_backtest_parallel`（§3.5.8）并行；乐观=净值×1.1 漂移近似，保守=×0.9。漂移在同一后复权口径下施加，分红再投关系保持一致。

## 4. 组合回测（基准按组合类型自动选择，默认全收益指数）

> **基准选择（闭合 E14）**：原默认硬写 `000300.SH`（沪深300 价格指数）对债券型/QDII/货基组合不当，且价格指数未含分红导致与组合（复权净值）天然存在分红缺口。改为：① 基准**默认取全收益指数**（含分红再投资），消除分红层面对比偏差；② 按组合底层资产类别自动选基准，用户可覆盖。

```python
# 全收益指数代码表(含分红); 用户可在请求中覆盖 bench
TOTAL_RETURN_BENCH = {
    "equity":  "H00300.SH",   # 沪深300全收益(权益型组合默认)
    "mixed":   "H00300.SH",   # 偏股混合型同权益
    "bond":    "CBA02701.CS", # 中债-综合财富(总值)指数(债券型组合默认)
    "money":   "CBA00101.CS", # 中债-总财富(1-3年)或货基可比基准
    "alt":     "H00300.SH",   # 另类(QDII/FOF)缺专用基准时回退沪深300全收益
    "qdii":    "SPXT.INX",    # QDII 用对应海外全收益指数(示例: 标普500全收益)
}

def _pick_benchmark(w: dict) -> str:
    # 按组合资产类别加权主导项选基准
    ac = load_asset_class_weights(w)        # {asset_class: weight}
    dom = max(ac, key=ac.get)
    return TOTAL_RETURN_BENCH[dom]

def portfolio_backtest(portfolio_id, window="3y", bench=None):
    w = load_weights(portfolio_id)                    # {code: weight}, 和=1
    bench = bench or _pick_benchmark(w)               # 默认全收益指数(闭合 E14)
    # 组合日收益 = Σ weight_i * 个基日收益(后复权净值对数收益)
    rets = pd.DataFrame({c: daily_return(load_nav(c, window, adjusted=True)) for c in w})
    port_ret = (rets * pd.Series(w)).sum(axis=1)      # 严格时序, 无未来函数
    bench_ret = daily_return(load_nav(bench, window, adjusted=True))
    # 再平衡: 默认月度再平衡回权重(可选 none)
    if REBALANCE_FREQ: port_ret = rebalance(port_ret, w, REBALANCE_FREQ)
    excess = (1+port_ret).prod() - (1+bench_ret).prod()   # 累计超额(复利口径)
    return {"cum_return": (1+port_ret).prod()-1,
            "max_drawdown": max_dd(port_ret),
            "sharpe": sharpe(port_ret),
            "bench": bench,
            "bench_cum_return": (1+bench_ret).prod()-1,
            "excess_cum": excess,
            "excess_ann": annualized_excess(port_ret, bench_ret)}
```

> **防未来函数**：所有 `daily_return` 用 `shift(1)` 对齐；窗口端点用实际交易日；回测起点 = max(各成分最早净值日, start)。组合与基准均用后复权/全收益口径，分红处理一致。

## 5. 边界与异常

| 场景 | 处理 |
|------|------|
| 区间内某成分净值缺失 | 该成分在缺失段收益置 0（持有现金），标 `partial=True` |
| 定投金额/频率为 0/空 | 40001 拒绝 |
| 组合权重和≠1 | 归一化并提示；>1.05 拒绝 |
| 分红口径 | 统一后复权净值（已含分红再投），**删除** `DIVIDEND_MODE`；与复权净值一致，杜绝双重计数（E3） |
| 赎回费 | `final_val` 扣赎回费参与 IRR；默认长期持有档 0%，可配（E3） |
| 基准缺失 | 按 `_pick_benchmark` 兜底；用户显式覆盖优先（E14） |
| 回测起点过近（<60 日） | 提示样本不足，仍返回但标 `low_sample` |

## 7. 测试验收（test oracle）

| 验收项 | 基准 |
|--------|------|
| 定投摊薄 | 下跌市中份额累积 > 上涨市同等投入（成本摊薄成立） |
| 无未来函数 | 用 `shift(1)` 校验：第 t 日收益仅用 ≤t 数据 |
| 组合基准 | 全仓沪深300全收益 时 excess_cum≈0（误差<0.5%，E14 全收益口径） |
| 分红一致性 | 同一标的用单位净值分支与后复权分支，累计收益偏差<0.5%（二选一互斥，E3） |
| 赎回费 | final_value = gross_value×(1−赎回费)，redeem_fee 字段可核验（E3） |
| IRR 一致性 | `_run_dca` IRR 与现金流 XIRR 公式一致 |
| 再平衡 | 月度再平衡后权重偏离 < 1% |
