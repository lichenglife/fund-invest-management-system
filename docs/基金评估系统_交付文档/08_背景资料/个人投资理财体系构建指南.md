## 一、认知篇：普通人凭什么在市场中赚钱

### 1.1 打破三个致命误区

| 误区 | 真相 |
|------|------|
| "投资就是炒股票赚快钱" | 投资是长期财富增值，短线交易是负和博弈（扣除手续费） |
| "我没有专业知识，不可能赚钱" | 指数基金定投的长期年化收益可达8%-10%，无需选股能力 |
| "等我有钱了再开始投资" | 复利的核心是时间，每月500元坚持20年比一次性投10万更重要 |

### 1.2 普通人赚钱的三个底层逻辑

**逻辑一：分享经济增长的红利**

过去20年（2004-2024），沪深300指数年化收益约8.5%（含分红），远超通胀和银行理财。只要中国经济持续增长，上市公司的利润就会增长，股价长期向上。

**逻辑二：利用"市场先生"的情绪**

> 本杰明·格雷厄姆："市场短期是投票机，长期是称重机。"

市场会因恐惧和贪婪出现极端定价。2008年、2015年股灾、2020年3月、2022年10月——每次恐慌性下跌都是买入良机。

**逻辑三：复利是世界第八大奇迹**

| 每月定投金额 | 10年后（年化8%） | 20年后（年化8%） | 30年后（年化8%） |
|:----------:|:-------------:|:-------------:|:-------------:|
| 500元 | 9.1万 | 29.5万 | 74.5万 |
| 1000元 | 18.3万 | 59.0万 | 149.0万 |
| 3000元 | 54.9万 | 177.0万 | 447.0万 |
| 5000元 | 91.5万 | 295.0万 | 745.0万 |

### 1.3 必读书单（按阅读顺序）

1. 《小狗钱钱》— 建立基础理财观念
2. 《指数基金投资指南》（银行螺丝钉）— 基金入门实操

## 二、规划篇：搭建你的财务地基

### 2.1 投资前的四项准备

```
第一步：3-6个月生活费的紧急备用金
     ↓ 存入货币基金（余额宝/零钱通），随取随用
第二步：还清高息负债
     ↓ 信用卡分期、消费贷等年化>10%的负债优先清偿
第三步：配置基础保障
     ↓ 意外险 + 百万医疗险 + 定期寿险（家庭支柱）
第四步：确定可投资资金
     ↓ 月收入 - 必要支出 - 短期目标储蓄 = 可投资金额
```

### 2.2 四个账户体系（标准普尔家庭资产配置改良版）

| 账户 | 比例 | 用途 | 投资工具 | 预期收益 |
|------|:----:|------|----------|:------:|
| **流动账户** | 10% | 日常开支+应急 | 货币基金、银行活期 | 1.5%-2% |
| **保障账户** | 20% | 保险保障 | 意外险、医疗险、重疾险、寿险 | 保障杠杆 |
| **稳健账户** | 40% | 保值增值 | 债券基金、银行理财、年金险 | 3%-5% |
| **进取账户** | 30% | 长期增值 | 指数基金、主动基金、股票 | 8%-12% |

> **年轻时（20-35岁）**：进取账户比例可提高到40%-50%
> **中年时（35-50岁）**：稳健和进取各占35%-40%
> **临近退休（50岁+）**：稳健账户60%+，进取账户20%-

### 2.3 收入分配实操公式

```
月收入100% = 必要支出50% + 储蓄投资30% + 提升消费20%

如果必要支出过高，优先压缩消费而非压缩投资。
记住：先储蓄后消费，工资到账第一时间转入投资账户。
```

## 三、配置篇：资产配置是免费的午餐

### 3.1 核心-卫星策略

这是最适合普通人的配置框架：

```
                    ┌─────────────────┐
                    │   卫星策略 30%    │
                    │  行业ETF/个股     │
                    │  可转债/REITs    │
                    │              │
                    │   ┌──────┐   │
                    │   │ 核心  │   │
                    │   │ 70%  │   │
                    │   │宽基指│   │
                    │   │数基金│   │
                    │   └──────┘   │
                    │              │
                    └─────────────────┘
```

**核心仓位（70%）— 不折腾，长期持有**

| 标的 | 建议比例 | 说明 |
|------|:------:|------|
| 沪深300指数基金 | 30% | 代表A股大盘蓝筹 |
| 中证500/中证1000指数基金 | 15% | 代表A股中小盘成长 |
| 标普500/QDII指数基金 | 10% | 全球资产分散 |
| 债券基金（纯债/二级债） | 15% | 降低波动，稳定器 |

**卫星仓位（30%）— 适度增强收益**

| 标的 | 建议比例 | 说明 |
|------|:------:|------|
| 行业主题ETF | 15% | 消费、医药、科技等长牛行业 |
| 优质主动基金 | 10% | 经过验证的基金经理 |
| 个股（如有能力） | 5% | 实践价值投资理念 |

### 3.2 动态再平衡规则

```
每半年检查一次：
  - 如果某类资产偏离目标比例超过5%，进行再平衡
  - 卖出超配资产，买入低配资产
  - 这是被动的"低买高卖"，是战胜市场的重要来源

示例：
  目标：股60% + 债40%
  当前：股70% + 债30%（股票涨太多）
  操作：卖出10%股票，买入债券，回到60/40
```

### 3.3 不同年龄段的参考配置

| 年龄段 | 参考组合 | 波动承受力 |
|:----:|------|:----:|
| 25-30岁 | 股80% + 债20% | 高 |
| 30-40岁 | 股70% + 债30% | 中高 |
| 40-50岁 | 股60% + 债40% | 中 |
| 50-60岁 | 股40% + 债60% | 中低 |
| 60岁以上 | 股20% + 债80% | 低 |

> 也可以用"100 - 年龄 = 股票仓位"作为简单参考。

## 四、执行篇：基金与股票实操体系

### 4.1 指数基金定投（首选策略）

**为什么是定投？**
- 摊平买入成本，避免择时风险
- 强制储蓄，纪律执行
- 心理压力小，容易坚持

**定投三原则：**

```
1. 选对标的：宽基指数基金（沪深300、中证500）
2. 长期坚持：至少3-5年，最好穿越一轮牛熊
3. 止盈不止损：跌了继续买，涨到目标收益再卖
```

**智能定投增强策略（估值定投法）：**

| 沪深300市盈率(PE)分位数 | 操作 | 定投倍数 |
|:---------------------:|------|:------:|
| < 20% 分位（极度低估） | 加倍买入 | 2倍 |
| 20%-40% 分位（低估） | 正常买入 | 1.5倍 |
| 40%-60% 分位（合理） | 正常定投 | 1倍 |
| 60%-80% 分位（高估） | 减少定投 | 0.5倍 |
| > 80% 分位（泡沫） | 停止买入，逐步止盈 | 0倍 |

> 数据查询：天天基金网、蛋卷基金、且慢等APP均有估值数据。

### 4.2 基金筛选五步法

```
第一步：看基金类型
  → 指数基金选被动型（跟踪误差<2%）
  → 主动基金选混合型/股票型

第二步：看规模
  → 指数基金：规模>2亿（避免清盘风险）
  → 主动基金：规模10-100亿（太小不稳定，太大不灵活）

第三步：看费率
  → 指数基金管理费应<0.5%/年
  → 主动基金管理费通常1.5%/年
  → 优先选C类（短期）或A类（长期>1年）

第四步：看历史业绩
  → 不只看短期排名
  → 看3年、5年年化收益是否稳定在前1/3
  → 看最大回撤是否在自己承受范围内

第五步：看基金经理（仅主动基金）
  → 从业年限>5年（至少经历一轮牛熊）
  → 管理规模与投资风格匹配
  → 风格稳定不漂移（大盘价值就坚持大盘价值）
```

### 4.3 股票投资实操框架（进阶）

> **警告**：股票投资需要更高的专业能力和心理素质。建议先用指数基金积累3年经验后，再考虑个股投资。

**价值投资四步法：**

```
1. 选行业
   → 消费、医药、科技三大长青赛道
   → 行业空间>1000亿，增速>GDP增速
   → 竞争格局清晰，龙头地位稳固

2. 选公司
   → ROE连续5年>15%（赚钱能力强）
   → 毛利率>30%（有定价权）
   → 经营现金流>净利润（利润真实）
   → 资产负债率<60%（财务稳健）
   → 股息率>2%（有真金白银回报）

3. 等价格
   → PE处于历史30%分位以下
   → PB<行业平均（重资产行业看PB）
   → 股息率处于历史高位
   → 分批买入，不要一次性满仓

4. 长期持有
   → 持有期>3年
   → 除非基本面恶化，否则不因股价波动卖出
   → 卖出条件：①极度高估 ②基本面恶化 ③找到更好的标的
```

## 五、风控篇：先活下来，再谈收益

### 5.1 投资中的六大风险及应对

| 风险类型 | 说明 | 应对策略 |
|----------|------|----------|
| **市场风险** | 股市整体下跌 | 资产配置+定投+长期持有 |
| **个股风险** | 单只股票暴雷 | 通过基金分散持有 |
| **流动性风险** | 急需用钱被迫割肉 | 3-6个月紧急备用金 |
| **通胀风险** | 购买力缩水 | 权益资产配置 |
| **行为风险** | 追涨杀跌，频繁交易 | 制定计划，纪律执行 |
| **认知风险** | 不懂乱投 | 能力圈原则，不懂不投 |

### 5.2 情绪管理三条铁律

```
铁律一：永远不因为"怕踏空"而追高买入
  → FOMO（Fear of Missing Out）是亏损的第一大原因
  → 市场永远有机会，现金在手就是选择权

铁律二：永远不因为"恐慌"而在暴跌中割肉
  → 2008年、2015年、2020年、2022年——每次恐慌后都创新高
  → 你卖的不是股票，是你积累的低成本筹码

铁律三：永远不满仓，永远不空仓
  → 满仓=没有选择权，空仓=没有参与感
  → 保持10%-30%的现金/债券仓位，攻守兼备
```

### 5.3 亏损时的决策框架

```
亏损时问自己三个问题：
  ① 我买入的逻辑变了吗？
     YES → 卖出，认错离场
     NO  → 进入下一个问题
  
  ② 我投的钱是短期内需要的吗？
     YES → 不该投的钱，找反弹减仓
     NO  → 进入下一个问题
  
  ③ 这个资产现在是不是更便宜了？
     YES → 如果有闲钱，应该加仓
     NO  → 继续持有，耐心等待
```

### 5.4 止盈策略

| 策略 | 操作方法 | 适用场景 |
|------|----------|----------|
| **目标收益止盈** | 达到年化15%-20%全部赎回 | 短期投资 |
| **分批止盈** | 每涨10%卖出1/3 | 震荡市 |
| **估值止盈** | PE进入历史70%分位以上逐步卖出 | 指数基金 |
| **不止盈** | 核心仓位长期持有不卖 | 宽基指数核心仓位 |

## 六、进阶篇：从入门到精通的学习路径

### 6.1 学习路线图

```
第一阶段（1-3个月）：基础认知
  ├── 阅读入门书籍
  ├── 了解基本概念（PE、PB、ROE、股息率等）
  ├── 开通基金账户，开始小额定投
  └── 目标：月定投500-1000元，建立感觉

第二阶段（3-12个月）：体系搭建
  ├── 完善四个账户体系
  ├── 建立核心-卫星配置
  ├── 学习估值方法
  └── 目标：形成自己的投资计划和风控规则

第三阶段（1-3年）：能力进阶
  ├── 深入研究2-3个行业
  ├── 开始小仓位个股实践
  ├── 学习财报分析
  └── 目标：年化收益稳定跑赢沪深300

第四阶段（3年以上）：持续优化
  ├── 形成成熟的投资哲学
  ├── 不断优化投资体系
  ├── 帮助身边的人
  └── 目标：长期年化10%-15%，实现财务自由
```

### 6.2 关键指标速查表

| 指标 | 含义 | 哪里查 | 用法 |
|------|------|--------|------|
| PE（市盈率） | 股价/每股收益 | 理杏仁、Wind | 越低越便宜，看分位数 |
| PB（市净率） | 股价/每股净资产 | 理杏仁、Wind | 金融地产等重资产行业看PB |
| ROE（净资产收益率） | 净利润/净资产 | 同花顺、东方财富 | >15%是优秀公司 |
| 股息率 | 每股分红/股价 | 同花顺、雪球 | >2%有现金回报 |
| 最大回撤 | 最高点到最低点的跌幅 | 天天基金 | 了解可能亏多少 |
| 夏普比率 | 收益/波动 | 天天基金 | >1说明性价比好 |
| 股债利差 | 股票收益率-债券收益率 | 且慢、蛋卷 | >3%股票有吸引力 |

### 6.3 推荐跟踪的信息源

| 类别 | 推荐 | 频率 |
|------|------|:--:|
| 估值数据 | 且慢"每日估值"、蛋卷基金估值 | 每周 |
| 宏观数据 | 国家统计局、央行报告 | 每月 |
| 基金研究 | 晨星中国、好买基金 | 每季 |
| 市场分析 | 雪球精选、有知有行 | 每周 |
| 财经资讯 | 财新、华尔街见闻 | 每天 |
| 社区交流 | 雪球、集思录（低风险投资） | 随缘 |

## 七、行动清单：30天启动计划

### 第一周：基础搭建

- [ ] **Day 1**：盘点个人财务状况（收入、支出、资产、负债）
- [ ] **Day 2**：计算3-6个月生活费，确认紧急备用金是否充足
- [ ] **Day 3**：检查保险配置（意外险+百万医疗险是底线）
- [ ] **Day 4**：还清或制定高息负债还款计划
- [ ] **Day 5**：在支付宝/天天基金开通基金账户
- [ ] **Day 6**：设置工资日自动转入投资账户（发薪日+1天）
- [ ] **Day 7**：阅读《小狗钱钱》

### 第二周：开始定投

- [ ] **Day 8**：确定每月可投资金额（收入的20%-30%）
- [ ] **Day 9**：选择第一个定投标的（推荐：沪深300ETF联接基金）
- [ ] **Day 10**：设置定投计划（每月固定日期，金额）
- [ ] **Day 11**：完成第一笔定投（金额可以小，动作要有）
- [ ] **Day 12**：了解PE、PB等基本估值指标
- [ ] **Day 13**：查看当前市场估值分位数
- [ ] **Day 14**：阅读《指数基金投资指南》前3章

### 第三周：配置完善

- [ ] **Day 15**：制定四个账户的目标比例
- [ ] **Day 16**：选择债券基金，建立稳健账户（推荐：纯债基金）
- [ ] **Day 17**：选择第二只宽基指数（中证500或创业板指）
- [ ] **Day 18**：配置完成核心仓位的70%
- [ ] **Day 19**：了解全球资产配置（QDII基金）
- [ ] **Day 20**：建立投资记录表（Excel或APP）
- [ ] **Day 21**：完成《指数基金投资指南》阅读

### 第四周：体系固化

- [ ] **Day 22**：写出自己的投资宣言（为什么投、怎么投、什么不投）
- [ ] **Day 23**：制定再平衡规则和时间表

### C. 最重要的十条原则

1. **不懂不投** — 能力圈外的一分不投
2. **长期主义** — 用3-5年不用的钱投资
3. **分散投资** — 不押注单一资产
4. **低成本** — 费率是确定的成本，越低越好
5. **纪律执行** — 计划你的交易，交易你的计划
6. **逆向思维** — 别人恐惧我贪婪，别人贪婪我恐惧
7. **持续学习** — 市场是最好的老师
8. **承认无知** — 没有人能准确预测市场
9. **保持流动性** — 永远不要让自己被迫卖出
10. **健康第一** — 投资是为了更好的生活，不要本末倒置
