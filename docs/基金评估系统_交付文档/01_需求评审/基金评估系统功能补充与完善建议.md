# fund-invest-management-system · 功能补充与完善建议

> **审视对象**：个人基金评估与模拟交易系统（fund-invest-management-system）
> **审视定位**：作为"个人基金学习利器"，现有 8 大模块还有哪些补充与完善
> **审视方法论**：
> - **基金分析技能** —— 四层级十维度框架、配置审查规则、单基深度评估（回本/情景/策略）、持仓舆情扫描
> - **股票研究专家视角** —— 基本面分析、估值建模（PE/PB/PEG/ERP）、财务健康、行业景气、αβ/CAPM、情景与压力测试
> **结论先行**：现有 8 模块已覆盖"数据→指标→评分→筛选→模拟→组合→学习→AI→风控"主线，但对照专业基金/股票研究能力，在 **宏观-市场研判层、组合多层级诊断、单基深度实验室、持仓穿透与舆情、研究型指标、数据溯源合规** 六个方向存在明显缺口，需补充完善方能成为真正的"学习利器"。

---

## 一、审视框架与现有功能覆盖度对照

### 1.1 用"基金分析四层级十维度"对照现有功能

| 层级 | 维度 | 现有模块覆盖 | 缺口判断 |
|------|------|------------|----------|
| **宏观背景层** | 经济周期/政策/事件驱动 | ❌ 无专门模块 | **严重缺失**：平台没有宏观看板，学习者无法理解"为何此时多配债/少配成长" |
| **市场博弈层** | 情绪/资金流/价格形态 | ⚠ 仅估值分位 | **缺失**：缺市场情绪(VIX/成交量)、资金流向(南北向/ETF申赎)、技术形态 |
| **标的质量层** | 赛道/财务/估值 | ⚠ 部分（估值分位） | **缺失**：缺行业景气、重仓股财务健康、ERP/PEG 等研究型估值 |
| **工具选择层** | 基金自身质量 | ✅ 评估引擎 | 已基本覆盖，但缺 αβ/跟踪误差/折溢价等研究指标 |

> **核心发现**：现有平台"重工具选择层、轻宏观与标的质量层"。作为学习利器，用户恰恰最需要前两层来建立"为什么"的认知。

### 1.2 用"单基深度评估流程"对照现有功能

| 单基评估环节 | 现有模块 | 缺口 |
|-------------|----------|------|
| 绩效回顾 | ✅ 评估引擎指标 | 覆盖 |
| 估值分位 | ✅ 估值信号 | 覆盖 |
| **回本测算** | ❌ 无 | **缺失**：`required_gain = |return|/(1+return)`，亏损教育的核心工具 |
| **情景推演** | ❌ 无 | **缺失**：保守/基准/乐观三情景，模拟盘压力测试 |
| **策略对照** | ❌ 无 | **缺失**：持有/定投/波段/调仓/止损五策略对比 |

### 1.3 用"配置审查规则"对照现有功能

诊断规则给出明确阈值（固收+货币 20%-55%、海外≥5%、黄金 5%-8%、科技AI≤15%、红利≥5%、医药≥3%、宽基必配等）。现有"组合与配置"模块仅有行业穿透/相关性，**未落地这些量化审查规则**，也缺"风险偏好判定"（固收+货币占比推导稳健/均衡/积极型）。

## 二、关键缺口识别（6 大方向）

### 缺口 A：宏观-市场研判层完全缺失
现有平台在"选基/评估"前，没有帮用户建立**仓位中枢**的判断能力。
- 缺宏观看板：PMI/CPI/PPI/GDP/利率/汇率
- 缺市场博弈：VIX、成交量、融资余额、南北向资金、ETF 申赎
- 缺"外围传导"研判（隔夜美股→A股开盘传导，基金分析技能明确要求优先分析）

**学习价值**：这是区分"盲买"和"懂配置"的分水岭。

### 缺口 B：组合诊断未落地多层级框架
现有"组合与配置"只做了回测/穿透/相关性，缺**四层级诊断**：
- 未做资产结构均衡审查（股债结构、海外、黄金、风格缺失）
- 未做"核心仓位类型缺失"识别（宽基压舱石、红利、海外）
- 未做"个基隐患"扫描（规模臃肿/长锁定期/高费率/高换手）
- 未做"市场高位信号排查"（估值/通胀/资金面/政策综合判断）

### 缺口 C：单基深度实验室缺失
评估引擎只给"指标+评分+归因"，缺**学习利器最需要的交互式推演**：
- 回本测算（让模拟亏损的用户直观看到"回本需涨多少"）
- 情景推演（保守/基准/乐观三情景目标点位与预期回报）
- 策略对照表（持有/定投/波段/调仓/止损的适用条件与优劣）

### 缺口 D：持仓穿透与舆情缺失
AI 助手只做了"研报解读"，缺**穿透到个股与舆情**：
- 持仓重仓股舆情扫描（逐股新闻情绪标注：正面/中性/负面）
- 重仓股基本面透视（财务健康：营收净利增速/毛利率/现金流/杠杆）
- 这是理解"基金为什么涨跌"的关键学习层

### 缺口 E：研究型指标缺失（股票研究专家视角）
评估引擎指标偏"绩效型"，缺"研究型"：
- α（选股超额）与 β（市场暴露）——CAPM 框架
- 跟踪误差、信息比率（指数基金核心）
- ETF/LOF 折溢价
- PEG、ERP（股权风险溢价）、盈利消化估值能力

### 缺口 F：数据溯源与合规标注不完整
基金分析技能强约束"结论必须可追溯到数据、标注来源与截至时间、附免责声明"。现有平台：
- AI 解读未强制标注数据来源与截至时间
- 评估输出未标注"数据截至日期"
- 缺全局免责声明与"非投资建议"水印

## 四、建议新增模块（从"工具"升级为"学习利器"）

### 新增模块九：宏观与市场的"认知底盘"
> 对应缺口 A、B、SA-01/SA-03

```
功能：
  · 宏观指标卡（PMI/CPI/PPI/GDP/利率/汇率，含趋势）
  · 市场情绪仪（VIX/成交/融资/南北向/ETF申赎）
  · 外围传导提示（隔夜美股/中概/A50 → 次日A股开盘研判）
  · 市场高位信号排查器（四维信号清单 → 高位/中性/低位判断）
价值：让用户先判断"仓位中枢"，再选具体基金——建立正确决策顺序。
```

### 新增模块十：单基深度实验室
> 对应缺口 C、SA-04/05/06

```
功能：
  · 回本测算器：输入当前收益/亏损 → 回本所需涨幅 + 三情景时间
  · 情景推演台：保守/基准/乐观三情景目标点位与预期回报
  · 策略对照表：持有/定投/波段/调仓/止损的适用条件与优劣
价值：把"评估"变成"推演"，让学习者理解不同操作的后果。
```

### 新增模块十一：持仓穿透与舆情
> 对应缺口 D、SA-07/08

```
功能：
  · 重仓股列表 + 占净值比
  · 逐股舆情扫描（情绪标注 + 来源 + 时间）
  · 重仓股财务透视（增速/毛利/现金流/杠杆）
价值：从"基金黑盒"穿透到"底层资产"，衔接股票研究能力。
```

### 现有模块增强（不单列模块）
- **评估引擎**：补 SA-09 研究型指标（αβ/跟踪误差/信息比率/折溢价/PEG/ERP）
- **组合与配置**：落地 SA-02 多层级诊断规则 + 风险偏好判定
- **AI 助手**：补 SA-07 持仓舆情、SA-10 数据溯源标注
- **学习投教**：补 SA-11 案例回放、SA-12 行为金融

## 六、股票研究专家视角的特别补充

从股票研究（基本面/估值/行业/财务/风险）专家角度，强调以下三点现有平台最该补的能力：

1. **估值必须多维，不只 PE 分位**
   现有估值信号仅用 PE 分位。研究视角要求补充 **ERP（股权风险溢价）、PEG、盈利增速能否消化估值**——尤其对成长/科技类基金，PE 分位高不代表贵（若盈利高增）。

2. **穿透到"好公司"标准**
   学习利器应让用户学会用**财务健康四件套**（营收净利增速、毛利率、经营现金流、杠杆率）评判重仓股，这既是基金研究也是股票研究的通用语言。

3. **情景与压力测试是风控核心**
   组合层面应支持**压力测试**（如"沪深300跌20%时组合回撤多少"），把风控从"事后预警"前移到"事前推演"。

---

## 七、总结

> 现有 8 模块让平台成为"能选基、能模拟、能评分"的**工具**；补充 SA-01~SA-12 与三大新增模块后，平台升级为"懂宏观、会诊断、能推演、可穿透"的**学习利器**。
>
> 最高优先级的三个补充：**组合多层级诊断（SA-02）、单基回本测算（SA-04）、数据溯源合规（SA-10）**——它们成本低、学习价值高、直接复用现有数据，应立即纳入 M1。
