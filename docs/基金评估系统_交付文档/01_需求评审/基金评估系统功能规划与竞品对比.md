# 基金评估系统 · 功能模块规划与竞品对比

> **系统定位**：个人学习 + 模拟交易 + 基金评估（非实盘交易、非基金销售）
> **对标对象**：天天基金、雪球基金（蛋卷）、支付宝（蚂蚁财富）、且慢
> **核心差异**：竞品是"卖基金的柜台"，本系统是"练投资的大脑"

---

## 一、主流基金平台功能盘点

先看清对手有什么，才知道差异化空间在哪。

| 平台 | 核心定位 | 主要功能模块 | 评估/分析能力 | 学习/模拟 |
|------|----------|------------|-------------|----------|
| **天天基金** | 数据最全的交易平台 | 基金排行、净值、盘中估值、自选、智能定投、定投排行、基金吧社区 | 收益排名强、估值实时、智能定投（成本定投/止盈） | 弱（靠社区自学） |
| **雪球基金/蛋卷** | 社区 + 组合 + 投顾 | 选基工具、组合构建、组合回测、行业穿透、偏离度、相关性、指数估值、投顾跟车、私募 | 组合分析强（三分法）、行业穿透 | 中（社区讨论为主） |
| **支付宝/蚂蚁财富** | 生态便捷、新手友好 | 基金超市、目标投、定投、投顾、智能选基 | 简单排名、目标投 | 弱（新手引导） |
| **且慢** | 投顾服务 | 四笔钱、策略跟投、估值表 | 跟投策略、估值 | 中（投教内容） |

### 竞品的共性局限（我们的切入点）

```
① 评估维度偏"收益排名"：首页几乎都是"近1年涨得多"的基金，
   诱导追高，不强调回撤/性价比/经理稳定性。

② 数据是"黑盒"：你能看结果，拿不到底层数据自己分析，
   无法验证平台的算法逻辑，也无法自定义。

③ 无"模拟交易"闭环：想练手？没有虚拟盘让你用自己学的
   方法试错、复盘，学和用是脱节的。

④ 评估为"成交"服务：强烈引导你买入，缺"什么时候该观望/
   该卖/该减仓"的逆向提醒。

⑤ 不做深度归因：基金为什么涨/跌、赚的是择时还是选股、
   风格有没有漂移，基本看不到。

⑥ 千人一面：所有人看到同样的排行，没有基于你自身风险
   偏好、持仓的诊断。
```

## 二、本系统功能模块规划（必备）

基于定位，系统需要以下 **8 大功能模块**：

### 模块 1：基金数据中心
| 功能 | 说明 |
|------|------|
| 全量基金库 | 按类型（股票/混合/债券/指数/QDII）分类检索 |
| 净值与估值 | 历史净值、实时/盘中估值（对接 AkShare） |
| 基础档案 | 规模、费率、成立日、托管行、跟踪标的 |
| 持仓透视 | 前十大重仓、行业分布、仓位变化 |
| 经理档案 | 从业年限、在管产品、历史业绩、风格 |

### 模块 2：基金评估引擎
| 功能 | 说明 |
|------|------|
| 指标计算 | 年化、夏普、卡玛、索提诺、最大回撤、波动率 |
| 多因子评分 | 收益/风险/经理/规模/费率/风格六维评分与排名 |
| 风格箱 | 大盘/中盘/小盘 × 价值/平衡/成长判定 |
| Brinson 归因 | 超额收益拆成配置/选股/交互 |
| 基金对比 | 多只基金并排比指标、比曲线、比归因 |

### 模块 3：智能筛选器
| 功能 | 说明 |
|------|------|
| 条件筛选 | 类型 + 回撤阈值 + 年化 + 夏普 + 经理年限 等组合条件 |
| 自然语言选基 | "找回撤<15%、年化>10%的红利基金"（LLM 驱动） |
| 评分排行 | 按综合评分/单维度排序 TOP 榜单 |
| 相似去重 | 持仓相似度聚类，避免重复配置 |

### 模块 4：模拟交易（核心特色）
| 功能 | 说明 |
|------|------|
| 虚拟账户 | 初始虚拟资金（如 100 万），不关联真实资金 |
| 买入/卖出 | 按当日净值模拟交易，记录成本 |
| 持仓看板 | 实时盈亏、成本、占比、与基准对比 |
| 定投模拟 | 设置定投计划，系统自动按历史净值回放 |
| 交易复盘 | 每笔交易标注"买入逻辑"，事后回看对错 |

### 模块 5：组合与配置
| 功能 | 说明 |
|------|
| 组合构建 | 核心-卫星、四笔钱等模板一键生成 |
| 组合回测 | 自定义时间区间，看组合历史表现 |
| 行业穿透 | 组合整体行业暴露、个股集中度 |
| 相关性分析 | 成分基金相关性，优化分散度 |
| 再平衡提醒 | 偏离目标比例触发提醒 |

### 模块 6：学习与投教
| 功能 | 说明 |
|------|
| 指标词典 | 每个指标点开看定义、公式、怎么用 |
| 案例库 | 经典基金/经理的深度拆解案例 |
| 学习路径 | 从入门到进阶的体系化课程地图 |
| 我的笔记 | 对每只基金/每笔交易写研究笔记 |

### 模块 7：AI 智能助手
| 功能 | 说明 |
|------|
| 研报解读 | 季报/年报自动提炼"这季干了啥" |
| 经理画像 | 多源信息生成基金经理人物卡 |
| 持仓变化分析 | 两期持仓 diff，说清加减仓逻辑 |
| 投资周报 | 每周汇总持仓、收益、市场、预警 |
| 问答 | 基于 RAG 知识库回答基金相关问题 |

### 模块 8：风险与监控
| 功能 | 说明 |
|------|
| 风险测评 | 评估用户风险偏好，匹配配置方案 |
| 预警中心 | 回撤超限、估值过高、持仓异动提醒 |
| 估值定投信号 | PE 分位 → 定投倍数建议 |
| 数据质量监控 | 净值缺失、异常波动自动告警 |

## 三、差异化特色功能（本系统的"杀手锏"）

对比竞品，以下功能是**自研系统独有、竞品普遍缺失或不开放**的：

### 特色 1：「学习 → 模拟 → 评估」闭环（最核心差异）
```
竞品：你看了排行榜 → 直接真金白银买 → 亏了不知道为什么
本系统：学指标 → 模拟盘用学的方法试 → 系统评估你的操作对不对 → 复盘改进

这是"训练投资能力"的完整闭环，竞品没有动力做（它希望你直接买）。
```

### 特色 2：可解释的自定义评估模型
```
竞品：评分逻辑是黑盒，你只能接受
本系统：权重你自己调（你觉得回撤重要就调高回撤权重）
        → 系统实时重排 → 你能理解"为什么这只排第一"
        → 培养你自己的投资框架，而非盲从平台
```

### 特色 3：深度归因与风格漂移检测
```
竞品：基本不提供，或只给简单同类排名
本系统：Brinson 归因告诉你"赚的是选股还是运气"
       风格箱检测"说好的价值基，是不是偷偷买成长了"
       这对识别"挂羊头卖狗肉"的基金极有价值
```

### 特色 4：模拟交易 × 实盘评估对照
```
你的模拟盘收益 vs 同期沪深300 / 同类平均
→ 客观评价"我的方法到底有没有用"
→ 跑赢基准再考虑小资金实盘，跑不赢先继续练
这是竞品完全不具备的能力（竞品只看真实账户盈亏）
```

### 特色 5：逆向提醒而非追涨引导
```
竞品：首页永远推"涨得最好的基金"
本系统：当某类资产估值进入历史高位 → 弹"注意泡沫，建议减仓/停投"
       当市场恐慌暴跌 → 弹"历史类似时点后续表现，可关注定投"
基于数据做"逆向陪伴"，对抗人性弱点
```

### 特色 6：个人持仓诊断（千人千面）
```
竞品：千人一面看同一个榜单
本系统：基于你的风险测评 + 现有模拟持仓
       → 诊断"你过度集中科技、回撤可能超承受"
       → 给"加配债券到 X%"的具体建议
```

### 特色 7：全量数据可导出 / 可二次分析
```
竞品：数据封闭，导不出，不能自己算
本系统：所有净值、指标、评分可导出 CSV/API
       → 你可以用 Excel / Python 做竞品做不了的分析
       → 真正"工欲善其事"
```

### 特色 8：AI 投研助手（RAG 基于真实数据）
```
竞品：AI 多是营销话术模板
本系统：RAG 接入基金合同/季报/你的笔记
       → 回答"这只基金的投资范围"基于真实合同而非编造
       → 自然语言就能驱动所有筛选/分析功能
```

## 五、模块优先级与路线图

不追求一步到位，按"学习价值密度"排优先级：

### P0（MVP，最先做）—— 验证核心闭环
1. **基金数据中心**（净值+基础档案）
2. **基金评估引擎**（指标计算+评分排行）
3. **智能筛选器**（条件筛选）
4. **模拟交易**（虚拟账户+买卖+持仓看板）

> 这 4 个模块即可跑通"学指标→筛选→模拟买→看结果"的最小闭环。

### P1（强化评估深度）
5. 深度归因（Brinson + 风格箱）
6. 组合与配置（回测 + 行业穿透 + 相关性）
7. 风险与监控（风险测评 + 预警 + 估值信号）

### P2（AI 与学习）
8. AI 智能助手（研报解读 + 自然语言选基 + 周报）
9. 学习与投教（指标词典 + 案例库 + 笔记）

### 持续迭代
- 自定义评估模型权重调节（特色1）
- 模拟 vs 实盘评估对照（特色4）

## 六、关键设计原则

```
1. 「不卖基金」是最大自由
   没有申购费收入压力，评估逻辑可以纯粹为"帮你做对决策"服务，
   敢做逆向提醒，敢说"现在别买"。

2. 透明优于智能
   宁可给可解释的六维评分，也不给一个不可解释的"AI推荐"。
   用户要的是"理解"，不是"被喂食结论"。

3. 模拟优先于实盘
   所有策略先在模拟盘验证，跑赢基准再谈真金白银。
   系统要持续回答："你的方法经得起回测吗？"

4. 数据主权归用户
   所有数据可导出、可二次分析，系统是工具不是牢笼。

5. AI 增强而非替代
   AI 负责解读、生成、交互；最终买卖决策权永远在人。
```

## 七、一句话总结

> 天天基金们是"基金的超市，希望你多买"；
> 这套系统是"投资的自习室，希望你多学、多练、少犯错"。
> 它用**模拟交易练手**、用**深度归因看透**、用**自定义模型思考**、用**逆向提醒对抗人性**——
> 这些是交易型平台天然不会给你的东西。
