# 基金评估与模拟交易系统 · 原型设计说明（Prototype Spec）

> **设计师角色**：Rapid Prototyper（快速原型专家）
> **原型目标**：用最低成本产出可点击低保真原型，验证"学→懂→筛→练→评→穿"核心闭环的可用性
> **原型形态**：单文件 HTML 线框（自包含、可浏览器打开、Tab 切换）、配色遵循金融翠绿专业风
> **配套文档**：《技术规格说明书》v1.2（本原型即其 UI 映射）

---

## 1. 原型原则（快速原型方法论）

| 原则 | 本原型做法 |
|------|-----------|
| Speed-First | 低保真线框，一天内可出全模块，不雕 UI 细节 |
| Core Flow 优先 | 先覆盖 Dashboard/筛选/评估/模拟/诊断/回本 主链路 |
| Validation-Driven | 每个页面标注"验证点"，便于用户测试时反馈 |
| 可点击即可 | Tab 切换模拟导航，不接真实数据 |
| 演进路径清晰 | 低保真 → 高保真 → 接 API → 生产 |

## 3. 核心用户流（3 条主链路）

### Flow A：选基评估流
`仪表盘 → 智能筛选器（设"回撤<15% 年化>10%"）→ 基金评估详情（看评分/归因）→ 加入模拟`

### Flow B：模拟练手流
`模拟交易（100万虚拟）→ 买入 → 持仓看板（盈亏/基准对照）→ 单基实验室（回本测算/情景）→ 复盘笔记`

### Flow C：组合诊断流
`组合与配置（核心-卫星构建）→ 组合诊断（提示行业集中/缺宽基）→ 宏观看板（定仓位中枢）→ 再平衡`

### Flow D：首页学习流（grill-me 新增）
`仪表盘（学一基卡）→ 数据中心（字段解释 / 经理风格箱）→ 评估详情（指标词典联动）→ 学习投教（案例回放）`

## 4. 页面清单与线框要点

| 页面 | 布局要点 | 验证点 |
|------|----------|--------|
| 仪表盘 | 状态区（4卡）→ 榜单区（类型Tab + Top10综合评分 + 近期动态）→ 学习区（学一基卡 + 学习入口）→ 折叠次要 | 进首页即得学习线索 |
| 基金数据中心 | 搜索+分类树+发现；档案分组+字段解释；净值复权/下载/盘中估算；持仓跳穿透；经理风格箱 | 全类型检索是否顺手 |
| 评估详情 | 指标卡（区间/基准）；五因子评分+因子分解；风格箱/Brinson/研究指标卡（阈值着色） | 评分是否可解释 |
| 智能筛选 | 左：条件表单（AND/OR）+ 右：实时结果；NL解析回显；单因子排序；相似去重提示 | 筛选是否高效可解释 |
| 模拟交易 | 账户/买卖（T日净值）/持仓看板（亏损联动回本）/历史定投回测/复盘笔记 | 练手是否直观 |
| 组合诊断 | 组合构建（导入模拟）；多层级诊断（红黄绿+建议）；回测；再平衡提醒 | 诊断是否 actionable |
| 宏观看板 | 宏观卡+情绪仪+外围传导；高位信号（四维→暗示）；股债中枢建议+跳转 | 宏观是否易懂可落地 |
| 单基实验室 | 回本测算（存笔记/联动）；情景推演（对持仓影响）；五策略对照卡 | 推演是否有用 |
| 持仓穿透 | 前十大（来源+时间）；四维度财务卡；舆情周评（统一出口） | 穿透是否清晰可溯 |
| 学习投教 | 指标词典（可引用）；角色三阶段路径；案例回放沙盒；行为金融问卷；笔记 | 学习是否体系 |
| AI 助手 | RAG对话（来源+拒答）；周报/持仓舆情周评；失败降级 | 交互是否自然可溯 |
| 风险与监控 | 风险测评（联动配置）；预警中心；估值定投信号（分位→倍数）；数据质量看板；高位排查（共享） | 守住边界是否可见可控 |

## 5. 设计系统（低保真规范）

| 项 | 规范 |
|----|------|
| 主色 | 翠绿 `#0f9d76`（专业/稳健，呼应金融） |
| 辅助 | 蓝 `#2563eb`（链接/操作）、红涨绿跌（A股惯例） |
| 背景 | 浅灰 `#f5f7fa` |
| 卡片 | 白底圆角 8px，轻阴影 |
| 字体 | 系统无衬线，正文 14px |
| 组件 | 线框占位（虚线框标注"图表区"），真实 input/button/select |
| 响应式 | 桌面优先，左侧导航 + 右侧内容 |

## 6. 原型范围与下一步

- **本期原型**：12 模块全部线框 + 可点击导航（低保真，无真实数据）
- **MVP 高保真**：优先 Dashboard/筛选/评估/模拟/诊断/回本 6 页接 API
- **演进**：低保真 → 高保真（真实图表）→ 接技术规格 Phase 1 后端 → 部署

## 7. grill-me 同步更新（v1.2 · DC-001~012 全闭环）

- **仪表盘（DC-001）**：由"概览卡+快捷入口"重构为**状态→榜单→学习 三段式**——顶部状态卡、中部类型 Tab+Top10 综合评分榜+近期动态、底部学一基卡+学习入口，并新增"折叠次要"区。对应 FR-D1~D6。
- **基金数据中心（DC-002）**：扩展为**全类型（含 ETF/LOF）+ 搜索/分类树/发现入口 + 档案字段解释 + 净值复权/下载/盘中估算 + 持仓跳穿透 + 经理风格箱**。对应 FR-01~05 增强。
- **③基金评估详情（DC-003）**：指标卡增加**区间/基准选择**（默认滚动3年、按类型自动选宽基）；综合评分改为**五因子（收益/风险/性价比/规模/经理，默认权重 30/25/20/15/10）+ 实时因子分解条 + 权重微调滑杆**，标注"引擎唯一权威源"；风格箱改为"持仓+回归交叉验证"；Brinson 标注"仅主动股混基"，指数/债基给出替代说明；研究型指标（FR-45）改为**分组卡片 + 阈值着色 + 一句话解读**；底部统一来源与交叉验证误差标注。
- **④智能筛选器（DC-004）**：条件表单改为**左表单 + 右侧实时结果（AND/OR 切换）**；自然语言框增加"已解析为条件"回显与兜底文案；结果表增加**单因子排序切换（综合/夏普/回撤/年化）**与**相似去重提示（重叠≥70% 一键去重）**；操作列支持"对比/模拟/组合"一键跳转。
- **⑤模拟交易（DC-005）**：买卖框标注"T 日收盘净值成交 / 非交易时段顺延"；持仓看板新增亏损基并**联动回本提示跳单基实验室**；新增**历史定投回测**面板；强调"账户可重置、不连通实盘"。
- **⑥组合与配置（DC-006）**：组合构建标注"从模拟持仓一键导入"；诊断报告改为**自动跑多层级诊断 + 红黄绿状态列 + 可操作建议**（股债/海外/行业/风格/个基）；新增再平衡提醒（偏离±5%）与相关矩阵说明。
- **⑦宏观市场看板（DC-010）**：新增**外围传导卡（隔夜美股/中概/A50→次日开盘研判）**；高位排查输出"阶段 + 一句话操作暗示"并标注与风险模块共享引擎；新增**股债中枢建议卡 + 跳转组合**；次要指标（PPI/GDP）折叠可展开。
- **⑧单基深度实验室（DC-011）**：回本测算增加"存笔记/联动模拟持仓"按钮；情景推演补"对持仓影响"列；策略对照升级为**五策略卡（含适用条件/优劣/适合人群）**并补"回本联动"行。
- **⑨持仓穿透与舆情（DC-012）**：重仓股表增加**来源 + 时间**列，标注"按占净值比排序、持仓季更/舆情日更、进入自动穿透 + 手动刷新"；财务透视改为**四维度卡片（增速/毛利/现金流/杠杆）**；舆情周评明确"由 AI 周报统一生成"。
- **⑩学习投教（DC-007）**：指标词典标注"全站 tooltip 可引用"；学习路径改为**角色三阶段 + 可跳转对应模块**；案例回放标注"独立沙盒"；行为金融改为"科普卡 + 自评问卷 + 改进建议"；新增个人研究笔记卡。
- **⑪AI 助手（DC-008）**：快捷指令增加"手动重跑周报"；对话增加**无依据拒答**样例与"来源+截至+仅供参考"标注；新增"持仓舆情周评（统一出口）"与"失败降级回退规则摘要"两块。
- **⑫风险与监控（DC-009 · 新增独立页面）**：补齐 BRD 模块八——**风险偏好测评**（问卷判定稳健/均衡/积极，联动默认配置与模拟起点仓位）、**预警中心**（估值/回撤/净值异动/持仓变化多类聚合 + 可设提醒频率）、**估值定投信号**（PE 分位→定投倍数映射 1.5x/1x/0.5x/停投 + 信号红点可订阅）、**数据质量监控**（采集成功率/时效/对账误差 + 异常告警看板，Must）、**高位信号排查**（四维 → 阶段 + 暗示，与宏观共享引擎）。风险页的"高位排查"与模块七宏观共用同一引擎，避免双套逻辑。

> 设计系统与低保真规范不变；字段解释采用 hover tooltip（原生 title），模块间跳转用跨页 `jump()`。全部 12 个页面（①~⑫）均已与 BRD v1.2 / grill-me（DC-001~012）结论对齐。
