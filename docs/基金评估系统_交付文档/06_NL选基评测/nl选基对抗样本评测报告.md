# NL 选基对抗样本评测报告（自由表述压测）

> 续接 `nl选基基线评测报告.md` 的任务 (a)。
> 目的：结构化 100 条已达 100%，但该结果是规整中文的地板。真实用户会写口语化、省略、错别字、中英混用的自由表述——本评测集专门压测规则兜底基线在自由表述上的**真实下限**，以完整回答「≥85% SLA 是否可达」。
> 配套：`nl_eval_set_adv.json`（60 条对抗样本）、`build_nl_eval_set_adv.py`（生成器）。基线解析器同 `nl_baseline.py`（规则兜底，无 LLM）。

---

## 1. 对抗样本设计（60 条）

| 类别 | 条数 | 模拟真实场景 | 规则层主要失分点 |
|------|------|-------------|-----------------|
| K 口语化/俚语 | 15 | "别坐过山车""躺赢""别一把亏光" | 俚语无法映射到因子 |
| L 省略/跨句指代 | 10 | "跟上面那个差不多""就要昨天聊那种" | 指代无解→应反问，部分漏判 |
| M 错别字/谐音 | 10 | "混和基""股票鸡""收溢""白九" | 关键词整体失效 |
| N 中英混用 | 8 | "low risk""sharpe 高""volatile" | 英文词未识别 |
| O 非标准数字 | 7 | "十几个点""百分之二十""两成" | 中文数字/汉字数字抽不到 |
| P 组合自由表述 | 10 | 多约束口语长句 | 因子阈值难精确对齐 |
| **合计** | **60** | — | — |

## 2. 评测结果

```
样本数: 60  |  目标 SLA: >= 85%
总体准确率(严格):       28.3%  (17/60)
  反问识别正确:          7/8
  结构化完全匹配:        17/53
  结构化因子容差匹配+:   34  (类型/区间/剔除对，仅因子阈值差)
  宽松准确率(因子容差):  85.0%
分意图: K 5/15(33%) | L 7/10(70%) | M 0/10(0%) | N 1/8(12%) | O 1/7(14%) | P 3/10(30%)
SLA 结论: ⚠️ 未达（规则层地板即此，需 LLM 增强）
```

## 3. 关键发现

1. **规则地板在自由表述上从 100% 崩到 28%**——结构化与自由表述是两种难度，不能用结构化 100% 推断生产可达标。
2. **但"结构理解"仍达 85%（宽松）**：类型/区间/剔除在 85% 的自由表述里是对的，只是因子阈值常对不齐。说明规则层是**合格的安全网**——即使 LLM 故障降级到规则，主结构也不至于全错。
3. **三类表达是规则层的"硬伤"**（M 错别字 0% / N 中英 12% / O 汉字数字 14%）：关键词整体失效或数字抽不到。这正是 LLM 语义理解的用武之地。
4. **反问机制在自由表述仍有效**（7/8）——无类型/区间/数字的模糊句大多被正确反问，未臆测。

## 4. SLA 结论（对任务 (a) 的完整回答）

| 分布假设 | 规则层准确率 | 是否达标 |
|---------|------------|---------|
| 纯结构化输入 | 100% | ✅ |
| 纯自由表述输入 | 28%（严格）/ 85%（宽松） | ⚠️ 严格未达 |
| **50% 结构化 + 50% 自由表述（混合）** | **≈73%（严格）** | ⚠️ 未达 85% |

> 混合估算：规则层在 (100×1.0 + 60×0.283)/160 ≈ **73%**，低于 85% 红线。

**结论**：
- **≥85% SLA 在结构化输入上已由规则层证实可达**（100%）。
- **在真实（混合）分布上，规则层单独达不到 85%（≈73%）——LLM 语义增强是达标的必要条件，而非可选项**。这与 DC-004「LLM 解析 + 规则兜底 + 歧义反问」的设计完全吻合：LLM 负责把自由表述（错别字/中英/汉字数字/俚语/多意图）映射到结构化条件，规则层负责兜底与降级安全网。
- **SLA ≥85% 是「生产解析器（LLM + 规则）」的属性，不是规则层的属性**。本评测量化了 LLM 必须填补的缺口：需把自由表述准确率从规则地板 28% 拉升到 85%+，方能使混合分布整体 ≥85%。

## 5. LLM 路径必须修复的失败模式（开发期清单）

1. **错别字/谐音归一**："混和→混合""收溢→收益""白九→白酒""股票鸡→股票基"。
2. **中英混用语义**：`low risk / sharpe / volatile / high return / top 20% / long term` → 对应因子。
3. **汉字/中文数字解析**："十几个点→15%""百分之二十→20%""两成→20%""五个点→5%"。
4. **俚语→因子映射**："过山车/躺赢/别一把亏光→低波动低回撤""跑赢余额宝两三倍→年化收益≈6%+"。
5. **跨句指代**："跟上面那个差不多"需在会话上下文里解析（超出单句范围，需会话状态）。

- `nl_eval_set.json`（结构化 100 条）+ `nl_eval_set_adv.json`（对抗 60 条）= **160 条回归语料**，覆盖规则层可解与不可解两端。
- 建议：开发期将两者合并为 `nl_parse` 的回归套件；**对抗样本专用于压测 LLM 路径**，每次 LLM prompt/模型迭代后重跑，确保混合分布准确率 ≥85%。
