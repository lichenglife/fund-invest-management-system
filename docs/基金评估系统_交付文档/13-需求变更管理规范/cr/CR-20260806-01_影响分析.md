## 风险与缓解

- **风险 R-1（配色决策引发争议）**：红涨绿跌（A 股惯例）与翠绿=正（现行令牌/国际惯例）相斥，选错将返工。
  - 缓解：作为评审决策点提交产品+技术联合确认；若选红涨绿跌，**先改原型§5+开发规范§10 再实现**（升 C3 子流程），避免先码后文档。
- **风险 R-2（内联色值遗漏）**：13 处 `#6B7280` 及游离色散落多文件，人工替换易漏。
  - 缓解：以脚本/正则全量扫描 + 新增 CI 断言（禁止出现令牌外十六进制色），确保零残留。
- **风险 R-3（Streamlit 响应式天花板）**：Streamlit 非原生响应式框架，`layout/columns` 在窄屏表现有限。
  - 缓解：采用"流式栅格 + 容器断点 + 关键页移动优先重排"策略（见改造方案），不强行套用 CSS 框架；必要时对核心页（仪表盘/筛选/交易）做窄屏专用布局。
- **风险 R-4（联调期示例数据误当真实）**：`MOCK_MODE` 默认开，若生产误带会展示假数据。
  - 缓解：生产镜像强制 `MOCK_MODE=0` + Docker Secrets；前端对"示例数据"角标强制贯穿；health 失败时明确降级提示而非静默。
- **风险 R-5（文档脱节）**：改造同步更新原型/开发规范，若漏则违反 R7。
  - 缓解：将"文档同步"列为 DoD 验收项，PR 检查清单包含原型/开发规范/CHANGELOG 三项。
