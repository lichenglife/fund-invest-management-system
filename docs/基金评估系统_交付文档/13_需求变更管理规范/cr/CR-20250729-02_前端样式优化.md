## 1. 背景与动机

仪表盘（`app/pages/01_仪表盘.py`）当前已跑通导航 + 三段式首页 + 综合评分榜，但视觉层存在以下问题（截图评审）：

1. **配色冲突**：金融场景红=跌/绿=涨，当前「全部」Tab 选中态用了红色下划线，与品牌绿、收益绿打架，易让用户误判为预警。
2. **标题区拥挤**：大标题 + 副标题 + 警告 banner + 收益卡片挤在一起，无呼吸感。
3. **警告 banner 简陋**：奖杯图标与文字未对齐、无背景/边框，像临时标注。
4. **指标卡片无层级**：「+12.4%」「+5.1%」无背景/阴影/边框，与页面背景糊在一起。
5. **Tab 默认样式**：字号偏小、选中反馈弱、下划线过细。
6. **表格默认样式**：rank/code 列宽不合理、无 hover / 斑马纹 / 对齐。
7. **侧边栏调试残留**：左上角深绿块里有「app」小字，像未删除的调试文字。
8. **收益缺少上下文**：无周期、是否年化、基准对比说明。
9. **无数据状态**：仅 4 行、无「数据截至 / 示例数据」标识，示例感强。

目标：在不改动任何功能逻辑、接口、算法的前提下，把前端视觉提升到「金融专业风」，并建立可复用的设计令牌与组件。

## 2. 变更内容

### Added（新增）
- `app/static/style.css`：金融专业风**设计令牌**（主色墨绿/翠绿、辅色浅绿、警告浅黄/浅蓝、文字三级灰、卡片圆角阴影）。
- `app/components/ui.py` 增强：`warning_card()`（警告/提示胶囊卡片）、`ranking_table()`（榜单表格封装）；`metric_card()` 增加周期标签与涨跌幅语义色参数。
- 可复用组件建成后，供 12 个页面统一调用。

### Changed（修改）
- `app/app.py`：注入 `static/style.css`；修正侧边栏顶部「app」调试文字为 Logo 区或移除；sidebar active 菜单项品牌绿高亮。
- `app/pages/01_仪表盘.py`：标题区间距、副标题次要色；警告 banner 卡片化；KPI 卡片改为圆角白底 + 周期标签 + 基准对比；Tab 选中态品牌绿下划线；表格列宽/表头/hover/斑马纹；增加「数据截至 / 示例数据」badge。
- 「金融语义配色」落实：收益正→翠绿、负→红；**禁用红色做选中态**。

### Deleted（删除）
- 侧边栏顶部「app」调试文字（R6 删除纪律：记录理由=调试残留；替代=Logo 区/移除；无兼容期 needed）。
- Tab 红色选中态样式（替代=品牌绿下划线）。
