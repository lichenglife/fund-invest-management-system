> **目标**：产出**可直接用于代码生成**的单一技术蓝图（具体文件路径、函数签名、数据库 Schema、API 端点、配置项）
> **原则**：KISS / YAGNI / DRY；最小架构开销；单文档策略
> **变更说明**：相对 v1.2，新增**难点 A 的解决方法学落地**——在 `domain/research.py` 中显式定义 **PEG/ERP 基金层代理算法**（重仓股/跟踪基准加权、盈利收益率减 10Y 国债、proxy 标注与缺失兜底），消除"naive 套用股票级指标"误导风险；其余内容（v1.2 已落地的 12 模块 DC-001~012 技术层）不变。

## 1. Problem Statement

- **Business Issue**：个人投资者缺乏"学指标→懂宏观→筛基金→模拟练→深评估→看穿透"的闭环工具；现有销售平台评估黑盒、无模拟盘、数据封闭。
- **Current State**：已有 BRD v1.2（**12 模块** / FR-D1~D6 + FR-01~48，全模块七要素 + User Story + 验收）、技术可行性评估 v1.1、决策纪要 DC-001~012（grill-me 结论）。尚无可运行代码。
- **Expected Outcome**：交付一套本地/轻量云可运行的 Python 系统，MVP（P0 强化）跑通"**仪表盘 + 数据中心 + 评估引擎 + 筛选器 + 模拟交易 + 组合诊断 + 回本测算 + 数据溯源**"闭环，后续阶段增量补齐宏观看板、单基实验室、持仓舆情、AI 助手、学习投教增强。

---

## 2. Solution Overview

- **Approach**：数据分析（pandas/empyrical/statsmodels）+ 自研业务逻辑（归因/评分/诊断/回本）+ Web 展示（Streamlit）+ AI 增强（LangChain+Chroma+低价 LLM）。批处理为主，AI/舆情走定时任务。
- **Core Changes**：
  1. 建立 PostgreSQL + Parquet + Chroma 三层存储
  2. 数据采集层（AkShare/Tushare/国家统计局）每日增量更新，**覆盖全类型含 ETF/LOF**，场内价/折溢价单独采集
  3. 评估层（指标/评分/归因/诊断）复用开源库 + 自研交叉验证；**评估引擎为唯一评分权威源**（筛选器/仪表盘只读引用，DC-003）
  4. 模拟交易层（虚拟账户闭环，T 日净值成交 + 非交易时段顺延）
  5. 仪表盘聚合层（状态/类型Tab Top10/近期动态/学一基）
  6. Streamlit 前端 + FastAPI 内部 API
- **Success Criteria**：
  - 核心指标与公开源/开源库对账误差 < 0.5%（误差 >0.5% 标红，DC-003）
  - 组合诊断规则 100% 落地（FR-37）
  - 模拟成交单测 100% 通过
  - 所有对外数据标注"来源 + 截至时间"（FR-46）
  - 评分/筛选/仪表盘三处评分口径一致（单一权威源，DC-003）

# ===== PEG / ERP 基金层代理算法（消除难点 A，v1.3 新增）=====
# 背景：PEG=PE/盈利增速、ERP=股票预期收益−无风险利率，本是"股票/指数级"指标。
#       基金无直接"盈利"，naive 套用会误导 → 全部改为"代理值(proxy)"并显式标注。
# 数据来源：个股 PE/增速/盈利取自 Tushare/AkShare；10Y 国债收益率(r_f)取自国家统计局/利率接口；
#          持仓权重(w_i)取自 holdings 快照（eval_date 口径），指数权重取跟踪基准成分。
RISK_FREE_RATE_SRC = "cn_10y_gbond"        # 10Y 国债收益率数据源键
PEG_PROXY_METHOD   = "holdings_weighted"  # 主动基：重仓股加权；指数/ETF：跟踪基准加权
ERP_PROXY_METHOD   = "ey_minus_rf"        # 组合盈利收益率 EY − 10Y 国债

def peg_proxy(code, as_of, holdings_snapshot) -> ProxyResult:
    """
    基金层 PEG 代理值。
    - 主动股混基(type∈BRINSON_SCOPE)：PEG_fund = Σ_i (w_i × PEG_i)，w_i=第 i 大重仓股占净值比，PEG_i=PE_i/盈利增速_i
    - 指数/ETF：按跟踪基准成分股权重加权 PEG_i（等权近似仅当成分权重缺失时）
    - 债基：返回 None（债基无权益 PEG 意义）
    - 兜底：持仓快照陈旧(>90天)或缺失 → 回退跟踪基准口径；均不可得 → proxy_available=False，绝不硬算
    返回 ProxyResult{value, method, is_proxy=True, as_of, source, available}
    """
def erp_proxy(code, as_of, holdings_snapshot, rf_rate) -> ProxyResult:
    """
    基金层 ERP 代理值。
    - EY_fund = Σ_i (w_i × E_i/P_i) 组合加权盈利收益率；ERP_fund = EY_fund − r_f（10Y 国债）
    - 指数/ETF：直接用跟踪基准的 ERP（成分加权 EY − r_f）
    - 债基：返回 None
    - 兜底：持仓缺失 → 跟踪基准口径；不可得 → available=False
    """
# 展示约束（硬性）：cards 中 peg/erp 的 name 后缀必须带"(代理)"，interpretation 必须含"相对高低提示，非绝对结论"；
#                available=False 时卡片显示"数据不足/代理值待定"，禁止展示任何数值。
